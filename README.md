# yurarium.github.io

Static site for [Yurarium](https://github.com/yurarium/yurison), a bibliographic database of
Japanese yuri manga.

Built artefacts only. Records, adapters and documentation live in the `yurison` repository; this
repo holds the compiled data and the page that reads it.

- `/`: placeholder
- `robots.txt`: disallows all crawlers

The site is self-contained: no external requests, no scripts or fonts from other hosts, no cover
art or manga of any kind. Bibliographic facts are not copyrightable; original classifications and
notes are CC0. Source data remains under its own terms: see
[DATA-LICENSE](https://github.com/yurarium/yurison/blob/main/DATA-LICENSE.md).

Removal requests: see [TAKEDOWN](https://github.com/yurarium/yurison/blob/main/TAKEDOWN.md).
